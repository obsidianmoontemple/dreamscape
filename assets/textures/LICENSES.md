# Texture licences

## Photographed surfaces (`photo/`, added 16 October 2026)

Every picture in `photo/` is made from a material on **ambientCG** (https://ambientcg.com) by Lennart Demes and contributors,
released under **CC0 1.0 (public domain dedication)**: free to use, change and sell, with no attribution required. Credit is given
here anyway. The 1K-JPG downloads were fetched through the jgengine asset mirror
(https://github.com/Noisemaker111/jgengine/releases/tag/packs), which re-hosts ambientCG's own zips unchanged.

The colour photo was turned grey, darkened by its ambient-occlusion map where one ships, evened to a pale brightness (so the game's
own colour for a wall or floor still decides its colour) and saved at 512 pixels (phones, headsets) and 1024 pixels (`-1k`, computers).

## Window reflection (`env/city.jpg`, added 16 October 2026)

A street panorama from **Poly Haven** (https://polyhaven.com/hdris), released under **CC0 1.0 (public domain dedication)**,
taken from the `hdri/city.exr` file of the npm package `@pmndrs/assets` 1.7.0 (CC0), which ships Poly Haven panoramas resized to
512 x 256. It was tone-mapped to an ordinary picture and is used only as the reflection seen in windows and glass walls.

## Leaf sprays (`photo/leaves.png`, added 16 October 2026)

Drawn for the game (leaf shapes, veins and twigs placed by a script), with the mottling inside each leaf taken from the ambientCG
material Grass004 (CC0, above). Stored grey with see-through gaps, so the season's colour still decides the tree's colour.
