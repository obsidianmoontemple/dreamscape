# Model licences

Every model under `assets/models/` is **CC0 1.0 (public domain dedication)**: free to use, change and sell, with no attribution required.
Credit is given here anyway, as the authors ask. Each licence below was read from the licence file that ships with the
downloaded pack (quoted), not from a web page. Where the download came through a GitHub mirror, both the author's own page and the
mirror (with the original licence file in it) are given.

The files were converted for the web: animations and skins removed (except under `characters/`), normals and picture
coordinates stored more compactly, large textures reduced in size. CC0 allows this; the shapes are the authors' own.

Files under `characters/` are the rigged, animated people and creatures the game now dresses its figures in (the player, other
dreamers and the city's people: `figures-hd.js` in the app). They keep their skins and animations. Only the files the game
loads are in the repository: `characters/quaternius/` (bodies, outfits, hair, the Universal Animation Library and their
textures), `characters/kaykit/` (the skeletons and their animation rig), `characters/creatures/` and `characters/kenney-mini/`.
Each folder also carries the pack's own licence file. A few files the lists below name for these packs are not in the repository,
because the game does not load them: the KayKit adventurers (barbarian, knight, mage, rogue, rogue-hooded), Kenney's mobility aids
other than the plain wheelchair, the second animation library (`anims-ual2.glb`) and the separate eyebrows. `SkeletonUtils.js` (three.js r128, MIT) clones the rigged figures.

Not used, because their licence is not CC0: Quaternius "Bestiary / Dungeon Monsters" (Quaternius Asset License v1.0) and an
unlabelled "free city pack" in the same mirror (no licence file).
